01

측정 준비

연결을 기다리고 있습니다.
온도
— ℃
pH
—
pH 4~10 기준으로 보정한 값입니다.아직 받은 측정값이 없습니다.세트 선택은 기록 구분용입니다. 각 아두이노에는 해당 세트의 보정값을 적용하세요.
연결 도움말

USB로 아두이노를 연결하고 Arduino IDE의 시리얼 모니터를 닫으세요. 연결 버튼에서 연결된 기기를 선택합니다.

  • 온도센서 모듈
    VCC(+) → UNO 5V
    GND(−) → UNO GND
    DATA / 신호(S) → UNO A1
  • pH 센서 보드 PH-4502C
    V+ → UNO 5V
    G 두 핀 → UNO GND
    PO → UNO A0
    TO·DO → 연결하지 않음
    pH 전극 → 보드의 BNC 단자
터미널 블록 모듈의 핀 이름을 확인해 연결하세요. 선 색깔보다 VCC·GND·신호 표시를 기준으로 합니다. 통신 속도는 9600입니다.
02

실험과 기록

  1. 초기 뷰렛 눈금을 입력하고 기록 시작을 누르세요.
  2. 용액을 3 mL씩 넣고 섞은 뒤 타이머 리셋을 누르세요.
  3. 약 2분 동안 변화를 관찰하고, 값이 안정되면 현재 눈금과 색깔을 입력하세요.
  4. 측정점 저장을 누르고 다음 투입을 진행하세요.

기록 대기 · 0개

이번 투입 후 경과 시간00:00용액 투입 후 리셋을 누르면 시작합니다.

누적 투입 부피: — mL

초기·현재 눈금을 입력하고 기록 중에 측정점을 저장하세요.

첫 측정점 저장 후 초기 눈금은 고정됩니다. 뷰렛을 다시 채우지 않는 한 번의 실험을 기록합니다. 타이머 리셋은 저장된 데이터와 전체 기록 시간을 유지합니다.
