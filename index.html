산과 염기를 혼합하면 어떤 변화가 나타날까?

실험 전, 우리 조의 예상

정답을 먼저 찾기보다 관찰할 변화를 예상해 보세요. 아래 내용은 이 화면에만 임시로 입력되며 CSV에는 포함되지 않습니다. 연구노트에도 적어 두세요.

02

준비물과 안전

사용할 용액은 질량백분율 농도가 각각 5%인 염산과 수산화나트륨 수용액입니다.

같은 5%라도 같은 부피에 들어 있는 반응하는 이온의 수가 같다고 미리 가정하지 마세요.

준비물 확인

실험 전 꼭 읽으세요

  • 실험복, 실험용 장갑, 보안경을 착용합니다.
  • 실험 전 약품의 정보와 교사의 안전 안내를 확인합니다.
  • 용액이 피부나 눈에 닿지 않도록 주의합니다. 피부에 묻으면 즉시 교사에게 알리고 흐르는 물로 충분히 씻습니다. 눈에 들어가면 즉시 교사에게 알리고 세안 장치를 이용합니다.
  • 실험 후 남은 용액은 교사의 안내에 따라 종류별로 지정된 폐액통에 모읍니다. 임의로 섞거나 싱크대에 버리지 않습니다.
03

장치 설치

04

장치 준비 방법

  1. 비커에 염산 30 mL를 넣고 페놀프탈레인 용액을 2~3방울 떨어뜨립니다.
  2. 자석 젓개 막대를 넣고 교반기 위에 놓습니다. 교반기의 가열 기능은 끕니다.
  3. 뷰렛을 스탠드에 고정하고 수산화나트륨 수용액을 채웁니다. 뷰렛 끝의 공기 방울을 제거한 후 깔때기를 빼고 초기 눈금을 읽습니다. 초기 눈금은 반드시 0일 필요는 없습니다.
  4. 온도 센서와 pH 센서를 고정합니다. 측정 부분을 용액에 담그되 비커 바닥이나 젓개 막대에 닿지 않게 합니다.
  5. 센서 연결을 확인한 뒤 아두이노를 USB로 노트북에 연결합니다.
아두이노와 센서 연결선 확인
  • 온도 센서 모듈 · VCC → 5V / GND → GND / DATA → A1
  • PH-4502C · V+ → 5V / G 두 핀 → GND / PO → A0 / TO·DO는 연결하지 않음 / 전극 → BNC 단자

선을 바꿀 때는 USB를 분리하세요. 연결된 모듈의 핀 표시를 기준으로 확인합니다.

05

측정하기

1

연결하고 처음 상태 저장

측정 화면에서 세트 번호를 선택하고 아두이노 연결을 누릅니다. 온도와 pH가 표시되는지 확인한 뒤 기록 시작을 누릅니다. 초기·현재 눈금에 같은 값을 입력하고 색깔을 선택하여 누적 투입 부피 0 mL의 측정점을 저장합니다.

2

3 mL 넣고 타이머 시작

수산화나트륨 수용액 3 mL를 천천히 넣고 뷰렛을 잠근 뒤 타이머 리셋을 누릅니다. 교반을 유지하면서 온도·pH·색깔 변화를 관찰합니다.

3

투입 후 2분에 측정점 저장

투입 후 2분이 되면 현재 뷰렛 눈금과 색깔을 입력하고 측정점 저장을 누릅니다. 값이 계속 변한다면 그 상황도 연구노트에 적습니다. 다음 3 mL 투입부터 같은 순서를 반복합니다.

4

총 50 mL까지 측정

3 mL씩 누적 48 mL까지 넣고, 마지막에는 2 mL를 넣어 총 50 mL로 합니다. 마지막 투입도 2분 후 저장합니다. 중간에 뷰렛을 다시 채우지 않습니다.

5

기록 종료와 파일 저장

기록 종료를 누르고 측정점 CSV 저장과 전체 데이터 CSV 저장으로 두 파일을 모두 내려받습니다. 파일의 학생 정보와 측정값을 확인한 뒤 교사의 안내에 따라 정리합니다.

왜 2분 후에 저장할까요?

각 투입을 같은 조건에서 비교하기 위한 기준입니다. 반응이 정확히 2분 걸린다는 뜻은 아닙니다. 기다리는 동안 열이 주변으로 빠져나가므로 2분 후 온도는 투입 직후 최고 온도와 다를 수 있습니다.

보정 범위(pH 4~10) 밖의 값은 추정값입니다. 해당 구간의 정확한 수치보다 변화의 경향과 다른 관찰 근거를 함께 살펴보세요.

06

결과 해석하기

측정점 CSV로 그릴 그래프

가로축은 수산화나트륨의 누적 투입 부피(mL), 세로축은 각각 온도(℃)와 pH로 하여 두 그래프를 그립니다. 2분 후 저장한 값의 변화를 비교하세요.

전체 데이터 CSV로 살펴볼 변화

가로축은 경과 시간(초), 세로축은 온도 또는 pH로 합니다. 투입 직후의 온도 상승과 이후 냉각, pH 변화 과정을 관찰하세요. 투입 시점은 측정점의 시각·경과 시간과 연구노트를 참고합니다.

  1. 수산화나트륨의 누적 투입 부피에 따라 온도와 pH는 어떻게 변했는가?
  2. 붉은색이 나타나고 유지되는 구간에서 pH는 어떻게 변했는가?
  3. 온도 변화, pH 변화, 색깔 변화를 근거로 중화가 일어나는 구간을 어떻게 추정할 수 있는가?
  4. 두 용액의 질량백분율 농도가 모두 5%여도, 같은 부피에서 정확히 중화될 것으로 예상할 수 있는가?
  5. 예상과 측정 결과가 달랐다면 어떤 원인이 있을까? 실험 방법을 어떻게 개선할 수 있을까?
결론은 관찰 근거와 함께

색 변화가 나타나는 지점, pH 7 부근, 온도가 가장 높은 지점이 정확히 일치한다고 미리 가정하지 마세요. 세 가지 결과를 비교하고, 열 손실·측정 간격·센서 반응과 보정 범위를 고려하여 설명하세요.

결론 작성 순서: 우리 조의 주장 → 이를 뒷받침하는 수치와 관찰 → 과학적 설명 → 한계와 개선 방법

측정을 마친 뒤 측정 화면의 ‘결과 분석·정리’에서 CSV를 불러오고 그래프와 결론을 정리하세요. 보고서를 저장한 뒤 교사가 지정한 방법으로 제출합니다.

준비가 끝났다면 측정 화면으로 이동하세요.안내를 다시 열어도 센서 연결과 수집 중인 기록은 유지됩니다.
