# 중화 반응 탐구 노트

아두이노 Uno의 온도·pH 측정값을 Chrome에서 기록하는 수업용 웹페이지입니다.

## GitHub Pages 배포

1. GitHub에 공개 저장소를 만듭니다.
2. 이 폴더 안의 index.html, style.css, timer.js, notebook.js, app.js, charts.js, analysis.js, virtual.js, session.js와 fonts 폴더를 저장소 최상위에 올립니다. fonts 안의 글꼴과 OFL.txt를 함께 올려주세요. .nojekyll도 포함합니다.
3. 저장소 Settings → Pages를 엽니다.
4. Build and deployment의 Source를 Deploy from a branch로 선택합니다.
5. Branch는 main, 폴더는 /(root)로 선택하고 Save를 누릅니다.
6. 배포가 완료되면 Pages에 표시된 웹주소를 공유합니다.

## 학생 사용

Windows 또는 macOS의 최신 Chrome에서 웹주소를 엽니다. 학생 정보와 세트를 선택하고 USB로 준비된 아두이노를 연결합니다. 아두이노 연결 버튼에서 기기를 선택하고, 측정값이 나타나면 기록을 시작합니다. 각 아두이노는 해당 세트의 보정값이 적용된 측정 코드가 미리 업로드되어 있어야 합니다. 노트북이 보드를 인식하지 못하면 USB 드라이버가 필요할 수 있습니다.

연결: 온도 모듈 DATA A1, pH 보드 PO A0, 통신 속도 9600. 다른 프로그램에서 시리얼 포트를 사용 중이면 닫아야 합니다.

## 데이터

학생 정보와 측정값은 브라우저 내부 저장 공간에 자동 저장되며 GitHub로 전송되지 않습니다. 종료 후 두 CSV도 저장합니다. 같은 브라우저에서 이전 실험 이어하기를 선택해 복원할 수 있습니다. 선택한 세트 번호는 기록 구분용이며 아두이노 보정값을 변경하지 않습니다.

## 글꼴

나눔고딕을 포함합니다. 글꼴 라이선스는 fonts/OFL.txt를 참고하세요.


## 결과 분석·정리

- 측정 화면의 ‘결과 분석·정리’에서 기록 종료 후 현재 데이터의 사본을 가져옵니다.
- 첫 화면의 ‘저장한 CSV로 결과 분석하기’에서는 측정점 CSV와 전체 데이터 CSV를 다시 열 수 있습니다.
- 한 실험의 두 파일을 사용합니다. 학생 정보 또는 세트가 다르면 함께 불러오지 않습니다.
- 부피·시간 그래프와 관찰 요약을 확인하고 결과 해석, 결론, 한계와 개선 방법을 작성합니다.
- 작성 내용 저장(JSON)은 데이터와 글을 함께 보관하고 다음에 복원합니다.
- 보고서 저장(HTML)은 그래프와 측정점 표, 작성 내용을 담습니다. 인쇄에서 PDF로도 저장할 수 있습니다.
- 자동 요약은 중화 지점을 자동 판정하지 않습니다. 범위 밖 pH는 추정값이며 최고 온도는 저장한 측정점 기준입니다.
- 자동 제출 기능은 없습니다. 보고서와 원본 CSV를 교사가 지정한 곳에 제출합니다.
- 결과 작성 내용은 같은 브라우저에서 자동 저장·복원됩니다. 기기를 옮기기 전에는 전체 이어하기 파일도 저장하세요.

## 가상 실험 비교

ChemCollective 비커 CSV 원본을 분석 화면에서 선택합니다. 초기 전체 부피 기본값은 32 mL(염산 30 mL + 지시약 2 mL)입니다. 다른 조건이면 수정합니다. L은 mL로, K는 ℃로 변환하며 초기 전체 부피를 빼 누적 투입 부피를 계산합니다. 빈 비커와 초기 부피 미만 기록은 비교에서 제외하고, 없는 0 mL 값은 만들지 않습니다. 실제 측정점과 가상 실험을 공통 부피 축의 두 그래프로 비교합니다. 농도·지시약 양·온도·기록 시점·열 교환 조건 차이를 함께 해석합니다. 작성 내용(JSON v3)에는 가상 데이터와 설정이 포함되며, 실제 데이터 없이 가상 데이터만 있어도 이어서 작성할 파일을 저장할 수 있습니다. 이전 JSON v1/v2도 복원합니다. HTML 보고서와 인쇄에는 불러온 비교 그래프가 포함됩니다.

## 현재 수업 용액 조건

실제 실험은 1 M HCl 30 mL와 1 M NaOH를 사용합니다. 실제 페놀프탈레인은 2~3방울입니다. 가상 CSV 변환의 기본 초기 전체 부피 32 mL는 가상 실험의 염산 30 mL + 지시약 2 mL 조건이며, 실제 실험의 지시약 양과 구분합니다. 안내 01의 예상 질문은 세로 배치와 넓은 입력란을 사용합니다.

## 수업 진행 및 저장 보완 (2026-10-21)
- 학생 정보·예상·측정 기록·가상 데이터·개인 답변을 IndexedDB에 약 5초마다 자동 저장합니다. 새로 열 때 이어하기 또는 새 실험을 선택합니다. USB 연결과 기록 시작은 직접 다시 해야 합니다.
- 브라우저 저장 공간을 지우거나 다른 기기로 옮기기 전에는 전체 이어하기 JSON을 저장하세요. 저장 실패는 화면에 표시합니다. 자동 저장은 OneDrive 제출이 아닙니다.
- 측정 기록이 생기면 조별 학생 정보와 세트 번호를 고정합니다. 개인 작성자는 결과 분석에서 따로 입력합니다.
- 진행 단계, 누적 부피·색깔 확인, 두 CSV 저장 상태, 개인별 파일 저장·제출 안내을 제공합니다. 업로드 완료는 학생이 OneDrive에서 직접 확인합니다.
- 실제 CSV 및 분석 데이터는 종류별 50,000행, 파일당 50 MB까지 불러올 수 있습니다. 전체 이어하기 파일도 50 MB 제한입니다.
- 공용 노트북에서는 필요한 파일을 저장한 뒤 새 실험 시작으로 이전 학생 기록을 지우세요. 같은 실험은 한 탭에서만 진행하세요.

## 측정 기준 시간과 타이머
- 현재 대기 기준은 1분(60초)입니다. timer.js 맨 위의 MEASUREMENT_WAIT_SECONDS를 바꾸면 타이머, 실험 진행 안내, 분석 경고의 기준이 함께 바뀝니다. 설명 문구는 index.html에서도 맞춰주세요.
- 동그란 시작·정지·리셋 버튼을 사용합니다. 정지는 일시정지, 시작은 이어서 재기, 리셋은 00:00으로 초기화하고 멈추기입니다. 새 용액을 넣을 때 리셋 후 시작하세요. 타이머 정지는 센서 기록을 멈추지 않습니다.
- 새 이어하기 파일은 타이머의 실행·정지 상태를 보관하고, 기존 timerAt만 있는 파일도 복원합니다.
